عن الموقع

هذا الموقع منصة إخبارية ومجتمعية باسم مختار الشعابي (الجمل)، تغطي الأخبار المحلية في تعز ومديرية مشرعة وحدنان وقرية المسنح، مع متابعة مختصرة للأخبار الدولية، وإضافة محتوى توعوي وخدمي، وقسم معلوماتي عن أنواع القات.

الموقع مصمم ليعمل كصفحات ثابتة قابلة للنشر على GitHub Pages دون أي خادم (Server). تحديث المحتوى يتم عبر ملف posts.json.
